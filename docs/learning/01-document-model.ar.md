# الدرس الأول: نمثل المستند ونمنع اختيار صفحات غير صالحة

افتح crates/document-model/src/lib.rs ثم شغّل cargo test -p document-model.

- crate: وحدة Rust قابلة للبناء؛ workspace يجمع عدة وحدات في مشروع واحد.
- struct Document: نوع يجمع بيانات المستند. نخزن عدد الصفحات فقط الآن.
- u32: عدد صحيح غير سالب من صفر إلى 4294967295.
- impl: يضيف دوال مرتبطة بالنوع.
- Result<Self, DocumentError>: الدالة قد تنجح وتعيد مستندًا أو تفشل بخطأ واضح.
- enum: يحدد حالات الخطأ الممكنة بدل نصوص مبهمة.
- &Document: استعارة للقراءة؛ نستخدم المستند دون نقل ملكيته أو نسخه.
- pub: يجعل العنصر متاحًا لوحدات أخرى؛ الحقول الخاصة تحمي صحة البيانات.
- #[test]: اختبار ينفذه Rust للتأكد من السلوك.

Document::new(0) يرفض المستند الفارغ. PageRange::new(&doc, 1, 3)
يقبل صفحات 1 إلى 3 شاملًا الطرفين إن كانت موجودة.
هذا تحقق من البيانات؛ لم نقرأ ملف PDF بعد.

## تمرين اختياري
أضف دالة len إلى PageRange تعيد عدد الصفحات، واختبر نطاق صفحة واحدة
ونطاق 2 إلى 5. فكر لماذا نطرح start من end ثم نضيف واحدًا،
ولماذا لا يمكن أن يحدث طرح سالب بعد التحقق في new.
